# Module: Hero and Impact
Home route: centered profile hero, resume and route actions, four colorful stat cards, current-focus card, expertise/case carousels, and education/skills previews. Impact route: all metrics and case studies from data/resume.ts.
components/Counter.tsx animates from from to to when visible; renders the final value without JS and under reduced motion, and cancels animation frames on unmount.
Carousel.tsx provides labeled horizontal navigation with disabled previous/next controls at track boundaries. PageHeading.tsx provides the consistent icon, eyebrow, title, and description treatment on all route pages.
